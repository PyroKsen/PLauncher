# PLauncher

## Источник версий игр

Версии игр и ссылки на архивы читаются только из `version.txt` в репозитории
`PyroKsen/VersionsPLauncher` на GitHub, ветка `main`.
Если файл недоступен или содержит некорректный JSON, лаунчер показывает, что версия
сервера недоступна. Установленные игры при этом можно запускать.

## Фоновая работа в Windows

При первом запуске установленной версии PLauncher добавляет себя в автозагрузку
текущего пользователя. После входа в Windows он запускается скрыто; отключить
автозапуск можно в настройках автозагрузки Windows. Portable- и dev-версии
не регистрируются в автозагрузке.

Кнопка закрытия скрывает окно в трей, не останавливая скачивание. Через правый
клик по значку можно открыть лаунчер или закрыть его полностью. В фоне лаунчер
проверяет версии при старте и каждые 30 минут. Уведомления приходят для
установленных игр с известной локальной версией и доступным обновлением;
одна и та же версия не уведомляет повторно за один запуск лаунчера.

## Casualties Unknown

Идентификатор игры в серверном `version.txt`: `CasualtiesUnknown`. Вкладка включена
в автоматическую и ручную проверку версий. Пока запись игры или ссылка отсутствует,
скачивание недоступно. Когда ссылка появится, она подхватится после проверки версий.

Запись внутри объекта `games` в `version.txt` на GitHub:

```json
"CasualtiesUnknown": {
  "version": "1",
  "downloadUrl": "",
  "dirName": "Casualties Unknown",
  "exeName": "CasualtiesUnknown.exe"
}
```

Заполните `downloadUrl` прямой ссылкой на ZIP. Лаунчер ожидает файл запуска
`Casualties Unknown/CasualtiesUnknown.exe` внутри выбранной папки установки игр.
`dirName` должен совпадать с единственной корневой папкой внутри ZIP. При новом архиве увеличивайте
`version`. Папки `Casualties Unknown` и `CasualtiesUnknown` исключены из git и сборки.

Фон вкладки: `assets/images/backgroundCasualtiesUnknown.png`. Изображение
масштабируется по размеру окна с сохранением пропорций.

## Risk of Rain 2

Идентификатор игры в серверном `version.txt`: `RiskOfRain2`. Вкладка включена
в автоматическую и ручную проверку версий. Пока запись игры или ссылка отсутствует,
скачивание недоступно. Установленную игру можно запускать и без доступа к серверу.

Добавьте запись внутрь объекта `games` в `version.txt` на GitHub:

```json
"RiskOfRain2": {
  "version": "1",
  "downloadUrl": "",
  "dirName": "Risk of Rain 2",
  "exeName": "Risk of Rain 2.exe"
}
```

Замените пустой `downloadUrl` прямой ссылкой на ZIP, а `version` укажите для
подготовленного архива. Имя ZIP может быть любым. Внутри должна быть одна корневая
папка `Risk of Rain 2`, а в ней файл `Risk of Rain 2.exe` и остальные файлы игры.
Если фактические имена отличаются, укажите их в `dirName` и `exeName` на сервере.
Папки `Risk of Rain 2` и `RiskOfRain2` исключены из git и сборки.

Фон вкладки: `assets/images/backgroundRiskOfRain2.png`. Он масштабируется с
сохранением пропорций и обрезкой по краям, чтобы заполнить окно 1280 x 720.

Существующая папка `FreeTP` внутри папки Risk of Rain 2 сохраняется при обновлении
и повторной установке: лаунчер не записывает в неё файлы из ZIP, не удаляет её
содержимое и не добавляет туда новые файлы из архива. Если `FreeTP` ещё нет,
она устанавливается из архива как обычно. Защита действует в выбранной папке
установки; при смене папки игры сохранения автоматически не переносятся.

## Сборка

Локальная сборка установщика без публикации:

```bash
npm run build
```

После сборки в `dist` появятся:

- `PLauncher-Setup-<version>.exe`
- `PLauncher-Setup-<version>.exe.blockmap`
- `latest.yml`

## Релиз через GitHub Releases

Перед релизом увеличьте версию в `package.json`, например с `1.0.0` на `1.0.1`.

Для публикации нужен GitHub token с правами на Releases:

```powershell
$env:GH_TOKEN="ваш_token"
npm run release
```

Команда создаёт draft release в репозитории `PyroKsen/PLauncher`. После проверки его нужно вручную опубликовать на GitHub. Автообновление видит только опубликованные releases, draft-версии пользователям недоступны.

Если загружать файлы вручную, в GitHub Release обязательно должны быть все три файла из `dist`:

- `PLauncher-Setup-<version>.exe`
- `PLauncher-Setup-<version>.exe.blockmap`
- `latest.yml`
